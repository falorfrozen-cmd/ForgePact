# ForgePact v1.3.5

- Monster Density now stays active automatically when starting the game and moving between zones. You no longer need to press Apply for every map.
- Returning to an earlier map still avoids repeatedly multiplying the same monsters.
- Chaos Tower has been temporarily hidden until its Season 10 behavior is fully verified.
- The installer includes the updated ForgePact plugin.

Use ForgePact only with an offline / EAC-disabled copy of Hero Siege.
