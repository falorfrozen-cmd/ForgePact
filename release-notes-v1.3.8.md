# ForgePact v1.3.8

- **Install also sets up the HS Offline Tracker sensor.** If you use
  [HS Offline Tracker](https://github.com/falorfrozen-cmd/HS-Offline-Tracker),
  its live sensor now travels with ForgePact: press **Install** once and both are
  ready. No second download, no dropping a DLL in by hand.
- The sensor is a separate, read-only module. It reports gold, XP, kills, drops,
  the room and the satanic zone to the tracker and writes nothing to the game.
  If you do not use the tracker it simply sits there with nobody listening.
- **Remove Plugin** takes the sensor away again, along with everything else
  ForgePact installed.
- No changes to Special Content, drops, density or any other ForgePact feature.

Use ForgePact only with an offline / EAC-disabled copy of Hero Siege.
