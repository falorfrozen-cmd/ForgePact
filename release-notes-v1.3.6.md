# ForgePact v1.3.6

- Added support for Hero Siege 7.0.90.
- The first modded launch is ready immediately on the current game build.
- Game-update installation guidance is now clearer.

After updating Hero Siege, close the game and press **Install Mod Plugin** again before launching.

Use ForgePact only with an offline / EAC-disabled copy of Hero Siege.
